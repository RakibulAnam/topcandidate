# TopCandidate video studio (local-only)

Raw footage in → Claude edits → review → iterate → final Reel out.
Short-form 1080×1920 (9:16) MP4s for Reels / TikTok / Shorts, built on
[HyperFrames](https://github.com/heygen-com/hyperframes) (HTML → deterministic video).

Nothing here ships with the product, and no media is ever committed (see `.gitignore`).

## One-time setup

```bash
cd video-production
npm run setup            # fonts, GSAP, logos, SFX, HyperFrames skills, Whisper model (~1.6 GB)
npm run capture-ui       # optional: fresh phone-size screenshots of topcandidatebd.com → shared/ui/
```

Needs Node ≥ 22, FFmpeg, whisper-cpp (`brew install ffmpeg whisper-cpp`), Google Chrome.

## Everyday use

Open Claude Code **inside `video-production/`** (so `CLAUDE.md` and the HyperFrames skills load), then:

```bash
npm run new -- cv-mistake-01                  # creates projects/cv-mistake-01/{input,…}
# drop your raw video into projects/cv-mistake-01/input/
```

Tell Claude:

> Edit projects/cv-mistake-01 into a 35-second Reel. Keep my personality natural. Cut dead space,
> make the first 3 seconds aggressive, add Banglish captions, emphasize important words, use
> TopCandidate UI when relevant, add subtle sound design, and end with a strong CTA.

Claude ingests, transcribes, plans (`notes/BRIEF.md`), writes `edit.json`, snapshots, renders a
preview, and iterates. Ask for changes in plain language ("captions bigger", "remove the part
about LinkedIn", "make this feel less edited") — it edits the existing plan, it doesn't start over.

## Commands (all take the project name)

| Command | What it does | Output |
|---|---|---|
| `npm run ingest -- <p>` | analyze raw footage + transcribe | `working/`, `captions/` |
| `npm run build -- <p>` | compile `edit.json` → HyperFrames composition | `composition/` |
| `npm run snapshot -- <p> --at 1,5,9` | still frames for quick review | `previews/snapshots/` |
| `npm run check -- <p>` | HyperFrames lint / layout / contrast | terminal |
| `npm run studio -- <p>` | live scrub-able preview in the browser (no render) | http://localhost:3017 |
| `npm run preview -- <p>` | fast draft render | `previews/preview-NN.mp4` |
| `npm run render -- <p>` | final render: H.264/AAC, −14 LUFS, faststart | `output/final.mp4` + `.srt` |
| `npm run render -- <p> --no-music` | variant (also `--no-captions`, `--no-sfx`, `--no-overlays`) | `output/final-no-music.mp4` |

## Layout

```
video-production/
├── CLAUDE.md            agent operating manual (the editing loop)
├── guides/              BRAND · EDITING_RULES · CAPTIONS · MOTION · SOUND · CONTENT_GUIDE · EDIT_SPEC · PRODUCT_UI
├── templates/           5 story structures (talking-head, product-demo, job-seeker-pain, before-after, meme)
├── scripts/             setup · new-project · ingest · build · render · studio · capture-ui (+ lib/)
├── shared/
│   ├── brand/tokens.css         committed — palette/type tokens (mirrors apps/web)
│   ├── components/              committed — captions CSS + motion components
│   ├── fonts/ vendor/ logos/ sound-effects/   generated by setup (ignored)
│   └── music/ ui/ broll/ stickers/            your local media (ignored)
└── projects/<name>/     ALL ignored
    ├── input/           raw footage (read-only after ingest)
    ├── assets/          per-project images/clips/music you add
    ├── working/         proxy, audio, analysis.md, contact sheet, timeline.json
    ├── captions/        transcript.raw.json, transcript.json (corrected), captions.srt
    ├── edit.json        ← the edit plan (the thing revisions change)
    ├── composition/     generated HyperFrames project
    ├── previews/  output/  notes/ (BRIEF.md, REVISIONS.md)
```

## Music

No music is added by default. Put licensed tracks in `shared/music/` (or a project's `assets/`).
`npm run test-music` makes an original placeholder bed for testing. The HeyGen BGM catalog
(`npx hyperframes media-use resolve --type bgm --intent "…"`) works after installing the HeyGen CLI
and running `heygen auth login --oauth` — optional, and it's an external account.
